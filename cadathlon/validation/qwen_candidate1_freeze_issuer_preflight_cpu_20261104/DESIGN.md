# Candidate 1 freeze assembly from completed public proofs

This is a pure preparation component. It has no file, model, tokenizer, network,
process or private-input access. Its synthetic tests create fabricated public
records in memory; these are not actual model outcomes. No actual candidate
report, journal, calibration or validation body has been read in preparation.

`issue(blobs, pins)` accepts the exact public parent/worker reports, producer
outer receipt, independent recorded-statistic reconstruction review and its
outer receipt, plus the fixed 139-file producer source inventory. All bytes must
match independently supplied digests. Only the currently authorized candidate 1,
source inventory and calibration grant are supported. The function checks the
complete 3,200-context/3,232-native-call PASS, unchanged gates, recorded coverage,
terminal flags, provenance and absence of validation or revision authority.

The reconstructed review, freeze attempt and independent outer receipt bind
the reconstruction source manifest, source archive and execution grant in
addition to the entry script. The producer source inventory remains a separate
identity. The caller must independently authenticate these pins, including actual
process exits/reaps/group absence and the tested reconstruction source closure.
Supplying self-selected matching digests is not an authorization capability.

The result explicitly describes recorded-statistic reconstruction. It makes no
claim to recompute absent activation arrays, model argmax or invariance arrays.
The complete private inventory and scalar/domain reconstruction belong to the
separate verifier; this assembler checks its bound public review and matches
its coverage and gates to the producer. The producer's source-bound model asset
postchecks are admitted evidence, not a new model-body hash pass by this helper.

The function returns deterministic freeze bytes with validation and row-zero
execution authorization both false. The eventual root publisher must require
the real producer/reconstruction terminal receipts, publish once to a fresh
owned destination, retain the exact bytes, and bind them in a separate held-out
grant. This helper neither observes process state nor publishes an actual file.
Prior-read flags describe the new candidate at initial freeze; they do not
erase historical candidate-3 outcomes or authorize reissuing a freeze after
held-out evaluation. Candidates 2/3 require a separate reviewed successor.

The original 79-test component and independent missing-helper-closure negative
remain unchanged. The corrected regression freezes its old synthetic byte
bundle, avoiding the original test's accidental dependence on a changing schema
constant. That same corrected test fails against the old issuer and passes
against this successor. The complete successor suite has 88 tests.

The external proof runner authenticates all execution sources before local
imports, denies actual input/model/outcome paths, backend imports, networking
and child execution, and records source hashes before and after the tests.
Acceptance additionally requires the external tool's final exit and reap; a
report written before the runner's last close is not sufficient. These source
and Python audit checks are not an operating-system sandbox.
