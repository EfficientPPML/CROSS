# Public-weight Qwen SiLU-domain design proposal

Candidate1's complete416-context calibration passed and its original112-context validation failed. Those outcomes remain separate and unchanged. This proposal selects no new coefficients and runs no model. Its trigger is the observed failure category; the proposed bound does not use validation extrema, logits or token choices.

For a post-attention RMSNorm input x, positive epsilon and one gate-matrix row W_j, define a_j=W_j*gamma_post. Then |gate_j|=|a_j dot x|/sqrt(mean(x²)+epsilon) <= sqrt(1024)||a_j||2. This bound holds for every real input, with no calibration range assumption. The proposed public-only extraction checks all28 gamma[1024] and gate[3072,1024] tensors, positive epsilon, zero projection bias and pinned bytes. Exact dyadic product/square/sum arithmetic plus an exact rational check on the final square-root endpoint gives an outward binary64 bound for each row. The small helper and eight synthetic tests demonstrate that calculation; the actual checkpoint-weight pass has not run.

If an inverse-sqrt implementation has a uniform relative certificate |sqrt(v)*p(v)-1|<=delta on the actual variance domain, the same-input ideal gate bound expands by1+delta. Sampled polynomial errors cannot serve as this certificate. Existing rounded-first-affine Newton certificates can cover ideal-real iterations on declared domains; balanced/power polynomials need an actual rounded-polynomial interval certificate. An exact residual polynomial and Bernstein/interval subdivision are proposed, not implemented. Finite arithmetic, independently perturbed encrypted moments and CKKS/refresh errors require separate terms. A pre-gate vector error e contributes at most ||W_j||2||e||2 before gate arithmetic error.

The symmetric per-layer SiLU domain would use the maximum certified row bound, not any held-out extremum. This could be much wider and much more expensive than sampled domains; no degree, depth, precision or feasibility is promised. It also does not certify other inverse-sqrt/softmax domains or a full model.
