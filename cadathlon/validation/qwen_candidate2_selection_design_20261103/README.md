# Candidate2 selection-rule proposal

This is a public design proposal, not a selected candidate or model result. The independent shallow-routing guard review found no concrete blocker; no routing sources were edited. Candidate1's calibration success and original public-validation failure remain unchanged.

Candidate2 would change only the28 SiLU approximation entries. All113 norm entries and every softmax domain, exp polynomial and reciprocal schedule stay canonical-JSON identical to candidate1. The per-layer radius is `ceil((9/8)*(1+delta_l)*B_l)`, computed with exact rational multiplication and integer ceiling. B_l is the pinned outward public gate bound; delta_l must be a uniform relative inverse-sqrt certificate for that unchanged post-norm implementation. The12.5% margin is a fixed engineering reserve, not a proved CKKS/finite-arithmetic error allowance. It does not remove variance-domain or same-input-relation conditions.

Twenty existing Newton certificates are available. The eight polynomial certificates are independently being computed; their sampled grid errors do not count as uniform proofs. Provisional radii assuming the polynomial delta values are at most1e-6 span48–3601, with layer26 radius763 and layer27 radius3601. These are planning numbers, not finalized candidate domains.

Selection would retain the previous degree order and absolute SiLU target1e-4, using the exact implemented balanced-Chebyshev circuit. In addition to the existing16385-point whole-domain grid, a predeclared16385-point grid on the intersection with[-16,16] prevents a wide domain from coarsening the transition check. These remain sampled checks. If direct polynomials fail, the existing rational tanh construction is separately tested/costed with base degrees8/12/16/20/24, the same five-step reciprocal on[1,2.1], and fixed public doubling count. Every grid intermediate must be finite/in-domain; no target relaxation, clipping or oracle fallback is allowed.

Direct balanced depth is at most18. The provisional rational path costs92–196 levels depending on public radius and the first successful base degree. An all-rational upper-cost preview reaches13238 abstract levels atS32 if the prescribed fallbacks succeed; that is not a feasibility or HE result. Actual candidate2 analytic targets have not been tested. Failure of any prescribed candidate is preserved as unsupported, and norm/softmax changes require a separate design review.

The execution order proposed for later approval is: freeze all public certificates and candidate2; run the unchanged416-context calibration; run the already-frozen fresh112-context held-out workload; then run the original published112-context workload as a required regression with the same frozen candidate. No validation result may fit coefficients, and a new-set success cannot replace the published-suite obligation. The original suite is a regression at this point, not an untouched held-out claim. All numerical/aggregate/token gates and stopped-suffix behavior remain fixed.

No coefficient selection or model execution has occurred under this proposal. `domain_preview.json` labels every unresolved multiplier and the conditional cost assumptions.
