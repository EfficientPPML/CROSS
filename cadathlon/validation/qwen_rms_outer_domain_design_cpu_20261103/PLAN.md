It does not select coefficients, evaluate prompts/models, or claim encrypted feasibility.

Use the complete public embedding table, not a prompt sample, to initialize coordinate envelopes E_i=max_token |embedding[token,i]|. A tighter first-site bound may additionally use the exact maximum full-row squared norm over that same entire table. Let D=1024, head width h=128, epsilon be the exact positive configured binary64 value, and R bound every current residual coordinate. Every denominator v has exact-real lower bound epsilon; the upper input/post/final variance bound is epsilon+sum_i R_i²/D. No positive lower variance above epsilon is assumed: learned residual branches may cancel.

For a normalized vector z_i=gamma_i*x_i/sqrt(mean(x²)+epsilon), write z=diag(gamma)u with ||u||2≤sqrt(D). Each bias-free linear row w has |wz|≤sqrt(D)||w*gamma||2. Public biases, if present, add their absolute value; the audit must either include them explicitly or reject an unexpected bias inventory. Q/K pre-normalization head denominators therefore satisfy v_head≤epsilon+(D/h)||W_head diag(gamma_input)||F². Record all16 Q and8 K head bounds, plus their site maxima. These norms occur before RoPE and GQA. Ideal RoPE preserves L2; its actual rounded coefficient/operator error remains separate. Q/K magnitudes do not weaken the next native attention mixture bound: exact causal softmax is nonnegative and has row sum1 for every nonempty valid prefix.

Bound V coordinates with the same normalized-linear row formula. Repeat whole KV heads in the exact GQA order (each of8 heads twice), then use the row-stochastic attention convex-mixture bound per coordinate. Propagate the attention output by |W_o| times that coordinate envelope and add any output bias. Add this envelope to R to obtain the post-attention residual bound. This deliberately ignores correlation between different heads/tokens; no S²F materialization or private range inspection is needed, and the exact-native bound is independent of valid prefix length.

For the MLP, derive gate and up row bounds G_j,U_j from gamma_post. Native SiLU satisfies |SiLU(g)|≤|g| for every finite real g, so |SiLU(g_j)*up_j|≤G_j U_j. Apply |W_down| and any bias, then add the MLP envelope to the residual. Continue28 layers and bound the final denominator. Every reduction, product, square root and serialization must round outward; raw checkpoint dtype/bytes, exact FP32 promotion, tensor inventories and source hashes must be recorded as in the existing public gate-bound audit. A scalar/coarse reference uses Fraction arithmetic and checked outward square roots. A production extractor may accelerate exact dyadic sums but must retain independent exact spot checks and never replace the proof by sampled activations.

The first implementation should report both coordinatewise/Frobenius/L1 bounds and their costs, even if very loose. Optional future tightening may compose public matrices or certify operator norms; it must be independent of validation outputs. The native exact-real bounds alone do not certify the polynomial graph. That graph needs uniform normalization multiplier envelopes on the new intervals, a uniform SiLU envelope, and attention nonnegativity or an explicit row-L1 bound. CKKS/refresh errors also perturb variance, positivity and correlated identities and need separate margins. Native float32 reduction/add/sqrt rounding is likewise outside the ideal-real statement; the actual binary32 epsilon representation may be slightly below the configured binary64 epsilon. Do not market an exact-real epsilon floor as an already proved native-float32/CKKS interval.
