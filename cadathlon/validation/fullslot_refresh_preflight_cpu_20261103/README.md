# Full-slot refresh prelaunch evidence

This archive contains **public planning and prelaunch tests only**. The separate encrypted CPU attempt was still pending when this evidence was archived. It does not establish refresh accuracy, full-model inference, peak memory, a speedup, or calibration.

The proposed circuit uses all 65,536 slots independently at N131072, depth 49, dnum 4, Q100/P24. Actual log2(QP) is 3490.161581 below the 128-bit classical ceiling 3523, and actual P coverage passes. Budget 4/4 requires 106 rotation keys including conjugation, returns normalized level 25, and permits an encrypted square at 24. Raw rotation-key pairs occupy 51.34375 GiB; the existing key store requires 55,197,908,992 free bytes including its header allowance and 64 MiB margin. The prepared collector uses an individually owned child directory under `/dev/shm`, CPU 132–135, four OMP/BLAS threads, no healthy timeout and a 60-second cancellation cleanup grace.

This is a different workload from the successful period 128 refresh and Qwen2 records: the full-packed engine evaluates both real and imaginary ApproxMod branches, twice for meta precision 10. There is one periodic alias, so no periodic averaging occurs. The fixed new input contains 65,536 unique random values in [-16,16], including signed endpoints, ±14.2 and near-zero/zero probes. Both full-slot refresh and subsequent square retain the existing strict 1e-3 absolute-error gate. These tests are not uniform interval certificates or substitutes for accumulated model gates.

The [final preflight](prelaunch/report.json) passed 33 tests in 1.00 seconds (1.4052 seconds externally). All 99 source files were unchanged and their archive was read back byte-for-byte. Tests cover actual secure public primes without key generation, distinct slots, every-slot numeric gates, fixed tmpfs ownership, both key-generation aliases and seven codec entrypoints, input fingerprints, cleanup/restoration cancellation, archive content, initial-publication failures and parent/child source binding. The [public plan](public_plan/report.json) records alternative budgets/profiles without promoting them. The [resource audit](resource_audit/resource_audit.json) includes exact known payload inventories and prior same-Q/P public NTT-table sizes; its explicit exclusions prevent treating them as a total memory bound.

The [initial test failure](initial_test_fixture_failure/pytest.log) is preserved: one test's expected storage literal was mistyped while the implementation calculated the correct value. No encrypted computation occurred in that failed test run. Later source-bound tests also cover the independently reviewed guard and failure-publication fixes.

Existing component rings N16384/32768/65536 cannot be joined by relabeling their ring degree. A successful full-slot bound 16 refresh would still leave same-ring composition, larger public bounds, complete transformer error accumulation and production file stages unresolved.
