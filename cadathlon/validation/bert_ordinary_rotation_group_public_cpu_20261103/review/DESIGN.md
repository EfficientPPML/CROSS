# Isolated serial ordinary-rotation group

`GroupedCompiledRotation.rotate_many(value, ordered_indices, progress=None)` is a fresh opt-in executor. `create_grouped_arithmetic` constructs a fresh subclass exposing that method; the inherited ordinary `rotate` implementation and all copied base/runtime methods remain unchanged. This lab copies the reviewed raw completion seam and authenticated-lease module, but does not wire into the live loader, routing graph, prepared-key cache or server runtime.

A group has one immutable JAX ciphertext input. Zero indices alias it; negative indices normalize modulo slots; duplicates execute separately in requested order. Defaults cap requests at16, logical new result payloads at2GiB, and digits at512MiB. Oversized result requests fail before work. An unsupported field, representation, physical source-device combination, mutable source storage, or excessive digit cost chooses ordinary per-key execution before decomposition, under the same keyless authenticated-source and result bounds. Invalid metadata, missing keys or changed provenance fail closed. The proof's tiny contexts are explicit metadata fakes and cannot establish a secure CKKS profile.

Supported decomposition requires exact standard Barrett/sub31 primes, CD2, immutable uint32 source on one physical device, ordered Q prefix/P and max-Q partition boundaries. Every supplied raw key/map shape and dtype is checked before work. The constructed private kernel must reproduce the actual Q/P/partition contract. Two explicit-array bindings share same-input digits but preserve the reviewed ordinary key-product/ModDown/c0/map completion for each key. Controls are retained even after the facade cache removes its instance. No stacking of multiple key states occurs; each completed pair is released before preparing the next.

The copied lease authenticates the original key producer and binds identities; readonly host mappings and timestamps do not establish immutable contents. The caller still needs the authenticated loader's dedicated no-write lifetime. The owner checks original ciphertext metadata, key/backing state, control/accessor identities and every retained result around callbacks. Rotation clear, close, nested groups and ordinary rotation reject reentry while a group is active. Callback-driven context or ciphertext mutation fails before the next primitive. No Polynomial crosses a JAX transformation.

Readiness barriers cover source, prepared keys, digits, explicit controls and retained results. Any post-start failure conservatively quarantines the original owner, exception/traceback and backing references until process exit, even when subsequent barriers finish; reuse and successful clear are refused. Successful groups retain no digit/kernel wrapper or per-key state. Executables alone may survive within the bounded owner compiler. Weak-wrapper collection is not evidence of physical allocator release or original NTT backing-buffer reclamation.

Logical accounting excludes raw mapped keys, original ciphertext ownership, public table/control buffers, conversion/compilation temporaries, executable code, allocator reservations and quarantine storage. There is no performance, HBM-fit, secure-encryption, precision or production-promotion claim.

Current proof stages use mocked cleanup/metadata contracts followed by real JAX canonical public residue arrays and synthetic key operands. Tiny N16/N256 with Q12/14/26/28/52/100 and fixed maxQ100/d8 exercise alpha13 boundaries,11/15-index groups and edge requests. The factory mock demonstrates the opt-in API and zero-alias boundary; actual CKKS context/factory integration and loader-owned quarantine must be reviewed and proven separately before genuine encrypted use.
