# Experimental causal-softmax and direct-V PV successor

The new modules are `encrypted_qwen_causal_softmax.py` and `encrypted_qwen_attention_bypass.py`. They preserve the frozen candidate3 manifest, its stored exp8 power coefficients, rounded reciprocal first affines, original three-level later updates, K-specific counts and layer-specific five/six squaring rounds. The predecessor head/PV and RMS refresh-binding source copies remain byte-identical to their earlier proofs. No main runtime, package or release is changed.

`DESIGN.md` and `source-bound-v1` are the separately frozen public proposal:52 tests,896 schedules and18 sources. New owner files are excluded from that older proof. The owner proof has its own explicit inventory, collector, report and archive, and executes full65,536-slot synthetic payloads through the actual new Python owner loops. Only the primitive arithmetic, security/context seams and refresh are replaced by explicit ideal doubles. No backend, keys, model, private/native tensor, prompt or held-out outcome is loaded.

Each public query row is a separate16-head SIMD branch, preserving heterogeneous K rather than running a common maximum count. Scores enter atL21. After literal centering, mapped-t B2 refresh, fixed exp/initial inverse and exact squaring rounds with explicit continuations, each branch receives a final B2 refresh followed by a real output mask atL24. Disjoint branch outputs are added in original query order. The planner and independent tests account for every original first affine/update, primitive, refresh, level and actual scale; canonical and adjacent-ULP refresh returns are examples, not a prediction of refresh error.

Query0 has no probability ciphertext. The result explicitly records a direct-value query. The separate PV successor uses the actual expanded encrypted V0, fused into its final real weighted mask for mixed tiles, or through a standalone mask for S1. This preserves the original K1 shape simplification without invoking softmax or substituting native/plaintext V. S1 V24 reachesL23; mixed P24/V24 reachesL21. The later caller must propagate actual returned levels.

Construction binds typed complete contracts and context/layout/key/accessor identities. Every primitive independently checks output metadata against its input recurrence. Original arrays, retained powers/denominators/numerators/inverses, current operation inputs and captured results stay strongly owned through callbacks and refreshes. Tests replace payload wrappers while observing weak references, verify immediate rejection before any next primitive, and check cancellation/reentry and semantic annotation cleanup.

The independent numerical oracle uses the original stored power polynomial and rounded-affine/original Newton equations on compact head/key arrays, with the frozen sum-then-alpha initial denominator order. Physical packed reductions may round differently; unchanged fixed ideal tolerances cover their comparison. Tests cover allK2–32 for both round families, all28 contracts, partial and noncontiguous rows, hostile future/head/upper padding, real probability-to-PV composition, K1 V bypass, and centered-domain endpoints including zero-margin normalized-t ±1 cases. Injected bounded values in invalid refresh lanes demonstrate the actual masks in the ideal circuit, not an encrypted error guarantee.

The cost remains11,656 full-period refresh calls for S32 across28 layers; the162-key union covers head/RoPE/QK/PV/softmax/bootstrap only. This is not a practical HE latency or memory-peak claim. All B2/B4/B8..B128 certificates remain conditional exact-real envelopes. No preservation of noisy exp domains, floating/encoding/CKKS error, refresh correlation, full decoder block, full28-layer inference, vocabulary logits or file-handler readiness is established. In particular layers3/5/12/15 retain zero exp-domain margins; no accepted clear domain or coefficient was changed.

Development histories are retained separately. Passing development copies are post-terminal snapshots unless explicitly labeled source-bound; they are not retroactively described as startup-frozen evidence. The final collector must run the exact final test file once, after review, and preserve every failure and source mismatch.

An independent17-source negative proof found that the first draft inherited an incomplete fingerprint: final callbacks could change `num_moduli` without rejection. Both expected rejection tests failed on those exact old bytes; that capsule is retained verbatim. The successor now fingerprints all typed structural fields (`num_moduli`, precision, r/c, derived shape), modulus dtype and public-moduli-array identity, validates the complete structure before arithmetic, and retains the original public modulus array as well as ciphertext payload. Final/current/earlier-checkpoint and before-entry regressions cover both owners. The ideal double was updated to supply real public structural metadata rather than an artificial layout marker; numeric operations and gates remain unchanged.
