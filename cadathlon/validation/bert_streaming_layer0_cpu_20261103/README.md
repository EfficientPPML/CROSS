# Full-width BERT row-layout CPU proof

Seven plaintext cases passed against the pinned BERT layer-zero NumPy and Transformers oracles. Maximum absolute error was **1.95e-14**; the CPU wrapper took **12.12 seconds**, exited zero and was reaped. All four measured source hashes stayed unchanged. Cases retain padded queries and include the original three public pairs, a full 128-token pair, an interleaved boundary mask, only the final key, and a partial 17-token tile. Hidden width is 768, with 12 heads of 64 features and MLP width 3072.

This is **layout and exact-nonlinear semantic evidence**, not encrypted BERT, polynomial numerical readiness, a twelve-layer model, or MRPC evaluation. No weights, ciphertexts, private inputs or keys are archived here.

- [Raw result](report.json), [log](run.log), and [source inventory](source_inventory.json) preserve the successful run. `prototype/` contains the exact measured layout/checker and planning scripts; `sources/` contains their dependencies as byte-for-byte text snapshots.
- [Planning](planning.json) records 3080 simulated ciphertext products, 21360 rotations, and conditional attention depth `7+E+R`, plus one output projection level. Exponential/reciprocal circuits, normalization, MLP and refresh costs remain unresolved.
- Padded-query centered scores exceed the earlier `[-9,12]` interval. The boundary-mask case reaches `[-14.22,15.32]`; raw exponentials reach 4.50 million. Exact unnormalized accumulation cannot inherit the earlier normalized-squaring circuit's bounds.
- The hypothetical full graph/full-slot refresh union has 225 rotation keys, 108.98 GiB of raw key pairs. Full-slot period 65536 has no sparse alias averaging and is not covered by the period 128 refresh proof.
- The proposed nine-ciphertext ordinary-attention scratch count excludes all nonlinear, key, NTT, compiler and transfer workspaces. It is not an HBM bound or an implemented ciphertext lifetime schedule.

**BSGS path distinction:** the planning report's 59.1 GiB staged-key example concerns core `ctx.bsgs_matvec` (also used by the fixed single-token `PackedQwen1` path). The generic `PackedTransformer.linear` used by the separate full-width projection test already processes rotation keys sequentially. It still retains baby ciphertexts; its actual peak memory is unmeasured here. The core staged-key estimate is not a requirement of the generic path.

`independent_review/` preserves a separate review of an earlier layout source variant (`b5517804…`); the successful pinned run used `320b7409…`. The old review must not be counted as exact-source coverage of the newer variant. A subsequent [independent rerun](../row_streaming_layout_cpu/check_cnn_layout.json) passed all eight checks against the exact `320b7409…` source; its [review scope](../row_streaming_layout_cpu/direct_review_scope.json) and [source copy](../row_streaming_layout_cpu/reviewed_row_attention.py) preserve that separate result. `earlier_wrapper_failure.log` records a Torch mask-construction dtype failure. Its pre-fix wrapper bytes were not captured; successful source hashes do not apply to that failed attempt.

For reproduction, restore the measured dependency snapshots into a checkout or use an identical checkout, set `CROSS_ROOT`, and invoke `prototype/check_pretrained_block.py` with the pinned local checkpoint directory and a fresh `--output` directory. [source_inventory.json](source_inventory.json) records the exact original environment/affinity command. The original planning script references its historical `/tmp` evidence paths; use the archived reports rather than silently replacing their provenance.
