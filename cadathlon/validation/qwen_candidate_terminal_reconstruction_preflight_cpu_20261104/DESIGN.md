# Independent terminal reconstruction before first-pass freeze

This plan is derived from13 public source files whose hashes match the frozen139
checker inventory `ccd5834b83b9dfec2d3ea988fb395a61ec4b05ce3f2f54621f29200cbbb8e06a`.
No actual initial/selector/candidate outcome, calibration token file, private
journal, validation body, model asset or checkpoint is read here. The current
code independently derives workload/metric counts and checks synthetic stored
metric records only. Root owns the live candidate collector77543 and will own
any eventual real terminal reconstruction; this component has no activated IO.

The verifier reconstructs recorded scalar statistics, gates, ordered prefixes
and hashes. It cannot recompute nRMSE/maxabs or model argmax from activation or
logit arrays: those arrays are intentionally absent from the journals. Native
bare/captured and exact plain/observed invariance booleans likewise remain
source-and-report-bound producer observations. This limitation must appear in
the review and freeze receipt. Reconstructing statistics does not mean running
a native framework, approximate model, HE graph or independent array oracle.

## Public admission before private reads

An eventual root entry must first authenticate externally pinned139 inventory,
all source/archive members (including only the exact64MiB assessment exception
and96MiB total), the completed candidate parent/worker, original execution grant,
candidate binding/manifest, source-ready proof and independent root grant. All
original selected coefficients, protocol and protected rules remain fixed. The
source candidate is ordinal1; later ordinals require their separately reviewed
revision chain, never a synthetic metadata claim.

Require authoritative parent and child return codes, direct reaping and owned
group absence, exact report hashes and parent/worker linkage. A successful
scientific run requires both exits0; a complete scientific failure requires both
exits1 and all cleanup/source/asset/ledger conditions. Killed, incomplete, stale,
comparison-invalid, source, schema, IO or cleanup-interrupted runs cannot freeze
a candidate or authorize revision. Authenticate runtime/backend/environment and
candidate/calibration/model pins and complete process fields before admitting
private paths. Root may rehash the fixed3 model assets without constructing a
model; producer before/after asset authentication is represented by source-bound
`model_asset_postchecks_completed`, not an invented worker asset-hash field.

## Independent ordered replay

Generate the3200 expected entries independently:96 prompts×S1..32,16 seeds×4
native-teacher steps,16 seeds×4 own-candidate-free steps. Validate the exact
tokenizer calibration schema/order and each original seed mapping, including
the original416 workload subset. Compare every measured ledger prefix to the
original prefill or independently reconstructed chain. Teacher appends actual
native argmax, even when the candidate stops. Free appends actual candidate
argmax after every finite completed result, even a numerical/top1 failure.
Candidate-only free stop permits only subsequent unmeasured suffixes; a
comparison stop disables that dependent chain. Independent prefills/seeds must
still be attempted. No input deduplication or replacement is allowed.

Each phase journal must have the same exact typed entry, candidate manifest,
token tuple and SHA256 of little-endian signed64 token bytes. Native/exact/
candidate choices must equal their ledger counterparts. No choice is invented
for a stopped candidate. Strictly reject unknown statuses, missing/extra
evidence, typed aliases, seed remapping, wrong preceding argmax and unmeasured
records without a causal stop. The verifier must implement this replay itself;
calling the producer's `Result.validate()` is only an optional cross-check.

## Root reconstruction and freeze publication

The root verifier writes a public review with separate `verification_passed`,
`scientific_pass` and `complete_scientific_failure_eligible` fields. A failed
scientific outcome can be audited successfully without becoming PASS. Bind the
candidate/source/calibration/grant/protocol/model digests, complete private
inventory hash, ledger hash, all aggregate summaries and every required stage
check. Report recorded-statistic scope explicitly and emit no tokens, choices,
raw arrays or failure text publicly. Private review artifacts remain separate.

Attempt-all cleanup, source/assets/input rechecks and signal restoration must
finish before review publication; final write/close can still fail. Therefore
the root verifier cannot certify its own last publication. An independent
outer receipt must bind exact review/script hashes and actual exit0, direct
reap and group absence. Only after that receipt may a separate first-PASS freeze
attestation be issued. A self-published PASS-looking review is insufficient.

The heldout93 draft's per-attempt outer pin should be refined in a successor to
explicit `producer_outer_receipt_sha256`, `reconstruction_outer_receipt_sha256`
and `reconstruction_script_sha256`, plus exact independent review hash. The
freeze receipt must select the first complete PASS in at most3 distinct,
authorized attempts, permanently close selection, and bind immutable manifest,
model/protocol/arithmetic/reference and the previously frozen validation/tokenizer
metadata without opening validation bodies. Its prior-read flags are scoped to
this new candidate's evaluation: historical candidate3 row0 failure and earlier
tokenizer-only input construction remain preserved, not erased.

Heldout1088/row0 execution still needs its separate root grant and later source
closure. The freeze receipt is not a model launch, a token-read capability, or
permission to tune after validation. Actual private reconstruction remains
disabled until root independently authorizes its specific files and process.
