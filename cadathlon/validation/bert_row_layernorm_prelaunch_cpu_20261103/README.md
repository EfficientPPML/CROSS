# Full-width BERT LayerNorm prelaunch checks

The isolated candidate passed **155 CPU arithmetic, metadata, fixture and lifecycle tests** (pytest 3.12s; collector 3.3206s). Its 111 measured source files stayed unchanged and are preserved in `prelaunch-v1/sources.tar.gz`. This archive does not contain an encrypted result. The separate three-process ciphertext experiment was still running when these checks were archived, and the candidate has not been promoted to the released runtime.

The candidate computes attention and MLP LayerNorm independently for two fixed native layer-zero rows each, with width 768 in a 4,096-slot row layout. The planned eleven-level circuit uses N32768, Q26/P4, depth12, dnum8, 22 rotation keys and no refresh. The actual public preflight reports log2(QP)=853.2334, below the library's 881-bit ceiling, and seven actual switching-key partitions. This security preflight does not establish ciphertext correctness or full-model security/performance.

`native-preflight-v2/` preserves the repaired fixture generator's native check and six exact sources. Both fixed variance domains contain the selected native rows. Independent exact NumPy versus native differences are at most 7.11e-15; the fixed polynomial versus native output differences are 2.6504e-6 (attention) and 3.8390e-6 (MLP). Those approximation diagnostics are separate from the pending ciphertext-versus-fixed-polynomial gate of 1e-6 across all eight 16,384-slot checkpoints. The native generator computes upstream attention and MLP activations to create isolated component inputs; this exceeds the embedding-only P2 client boundary and does not implement the full file-stage contract.

The earlier native check and validator review are retained. The original validator accepted self-consistently rehashed token IDs and substituted finite oracle values. The repaired validator pins the native fixture token/input digests and independently recomputes all eight expected arrays from validated inputs and public model tensors. `norm-private-validator-review-v2.json` records rejection of both original attacks. This fixed-fixture validator is not a general input loader for arbitrary contestant requests.

`norm-transport-v2.*` records 73 backend-free public-key, model, two-input/eight-output transport and cleanup tests. Its mock security gate and broadcast test arrays check metadata only. Filesystem ownership checks are not an operating-system sandbox against arbitrary same-user processes. Earlier logs are preserved with their original source versions rather than relabeled as final results.

Only explicitly selected source archives, public plans, manifests, digests, aggregate diagnostics and logs are retained. No model arrays, private reference arrays, secret keys or ciphertext payloads are included. Run `python verify_archive.py` here to verify the recorded source archives and final test result. `archive_verification.json` records the archival checks and file digests. The source paths in original reports identify the experiment checkout; they need not exist to verify this archive.

No encrypted LayerNorm accuracy, full BERT layer/model composition, MRPC result, TPU timing, scoring calibration or cross-ring conversion is claimed. The LayerNorm, FFN and Q/K experiments use different rings and cannot be directly chained.
