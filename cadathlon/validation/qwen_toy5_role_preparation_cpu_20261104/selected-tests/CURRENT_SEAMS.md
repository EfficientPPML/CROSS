# Executable-source seams for the prospective55

The accepted plan and `IMPORT_SEAMS.json` are preserved historical specifications. This document describes the selected fixture implementation. Every intended failure has its own child; no private quarantine/owner registry is cleared to resume a failed role. The clean0/1 compose control repeats only clean recording bodies. All monkeypatch contexts restore their original callable in finally; changed test-owned context/array objects may remain quarantined until child exit.
