## What is implemented

`q5_key_contract.py` admits the original Q100/P24/d4/N131072/p56 profile, exactly100 literal rotations and203 public arrays, with one secret array and separate public/private manifests. It authenticates the fixed public profile and original replay metadata before deriving inventory. `q5_key_producer.py` preserves original Python-int secret identity through evaluation/rotation generation, captures original store callbacks, requires source/security/capacity before RNG, and emits only internal writer-consistency metadata. The default real entry denies.

The original43 loader body is selected with explicit Q5 types/imports and a source-fixed dependency branch. Its same-FD key readers, nonblocking opens, bounded pre-read NPY header checks, keygen-alias/seven-codec guards, serial role lock, original cleanup and failed-context/mapping retention remain. The selected74 key store changes imports and Q5 wording only: it retains external expected-parent checking before root creation and synchronous non-buffering NPY writes. `ActualBackend` binds genuine selected constructors, p56 codec methods, exact security functions and original aliases behind an unavailable runtime capability. No arbitrary injectable callable becomes actual authority.

The public toy asset layer generates only the exact original seeded35 weights, compares their raw float64 hashes with fixed public metadata, writes bounded held NPY files and validates immutable copies. Server only loads that store; it does not invoke the generator, derive embeddings or run the dense reference. Its nonblocking original descriptors remain held through owner use.

`q5_owned_io.py` bounds the in-memory encoder during `write`, `writelines`, `seek` and `truncate`. It closes the memory buffer before opening the sole output descriptor, then uses exclusive0600 write-all, held/named identity, hash readback and fsync. One input NPZ and46 checkpoint NPZs retain the six opaque fields and512-byte header bounds. Full manifest publication is last. The payload, encoding buffer, immutable bytes and readback copies add a resource obligation; the per-file cap is not a total memory bound.

Ciphertext consumers are acquired before transfer/reconstruction. Server uses its captured original cache/get_sliced_ntt_q accessor; codec-only client contexts use an explicit public NTT owner. Both supply `Polynomial.from_array(array, shapes, parameters)` with authenticated moduli and the retained NTT context. The client owner allocates original Barrett/NTT objects before invoking their original initializers and retains partial reachable arrays on failure. No shared-cache or implicit standalone fallback is allowed. Constructor-local objects never returned or attached remain outside that local observation; whole failed context/process quarantine is still required. Original payload/table barriers precede key-scope exit.

Setup uses the original packing (B2/S4/F32/period1024/64 replicas), one fresh L49 ciphertext and original canonical scale. Its post-generation IDs are writer-attested internal readback under the original preauthorized setup intent, not independent GeneratedReadiness. Later roles require externally pinned setup manifest/report/outer/root evidence and exact retained roots. Server performs the original216 events/19 refreshes and emits47 records (46 new files). Client checks every entire47 artifact before even opening private-manifest metadata, then reconstructs and strictly decodes each with the unbound default call `(ctx, value, scale=actual, slots_to_decode=65536, validate_approximation=True)` and immutable full snapshots. It fails fast; no alternative decoder, averaging or relaxed retry. Original nRMSE0.10/maxabs0.20 remain the final gate; top1 is diagnostic.

Original finish/close callbacks are captured on acquisition. Guards after finish and after original cleanup run inside the key scope. Successful close removes permanent strong-owner registry entries and clears borrowed mirrors; weak tombstones preserve idempotence. Failed or uncertain owners remain retained and cannot be reused. A class-only failure checkpoint can be published without converting its exception into a clean scientific FAIL. A report alone never proves normal completion: independently owned wait/reap/root admission must follow evidence close.

## What remains explicitly unimplemented and denied

The complete native dependency/origin policy, audit/device permissions, source/import transition authority, current resource/lease measurements, stage-specific key/body transition state and actual per-phase launch grants still require separately reviewed implementation and evidence. The old seven-module entry and new `q5_actual_entry` both deny. The new entry's argparse help/usage remain outside the protected terminal boundary; escaped exceptions map to70 and only normal exact int0/1 are potentially accepted. No conditional grants or proof instances are included. The new role schemas are proposals, not claims that their actual producers/root receipts exist. Existing public setup/server envelope checking resolves paths as metadata; no claim of a completely filesystem-free full phase check is made.

The source closure is complete as a declaration of these disabled adapters and selected public dependencies. It is not an executable actual-role closure, a focused test proof, an HE result, a first-divergence diagnosis, a precision repair or an actual launch authorization.
