# First-attention integration plan

This is a public implementation plan for pinned BERT layer0 from client embedding rows through attention output, residual and the first LayerNorm. It does not include the FFN, the remaining11 layers, pooler/classifier or ranked file-stage completion. `report.json` replays actual binary64 scale expressions and existing public key planners; no JAX, model forward, CKKS context, keys, ciphertexts or HE run is involved. The separate weight inventory reads four public checkpoint tensors after verifying the entire pinned safetensors SHA256; it saves only hashes and diagonal metadata.

The frozen arithmetic manifest remains SHA256 `4e2277beea7189aa1d77b168c500c8a175f6c630afa520fcc6b38cb5a179cff9`. Ordered Q100/P14, N131072/CD2, layout256×512, dnum8, depth49 and p60 are unchanged. The actual QP bound is3402.080255733439bits; integer security and P-partition coverage are rechecked. Physical slots hold16 distinct rows at pitch4096, first768 features, with no periodic aliases. A score tile is16 rows of128 keys×16 padded heads in each lower2048 half;12 heads are active. Every source and query tile preserves original position embeddings.

If a future path fails that guard, it needs a real alignment operation and a revised plan, not metadata relabeling. The row-normalization helper owns an arithmetic cache facade but borrows the context; phase transitions must be serial and must not close that context or clear a concurrently executing owner.

## Domain and numerical obligations

The frozen v2 training selection explicitly excludes padded-query observations; approximate training/dev compact valid public tokens. Therefore that evidence does not certify all128 query rows of padded fixtures. The all128 resource/layout plan preserves BERT's key-only mask and is algebraically correct, but its padded-query centered-score and LayerNorm domain coverage needs a separate public audit. The selected orchestration uses the explicitly declared valid-query compact contract with original learned positions preserved, while retaining eight fixed K/V tiles for the existing assembly API; do not label this as all128-row output equivalence on padded fixtures. No domain or coefficient is expanded here.

For each live query/head, retain the centered-score contract[−16,16], initial mean-exp[.5,2], and each squared denominator[.5/K,2]. Exact-real probability mass near1 does not establish these after HE and refresh. If incoming ideal mass is m, ideal L2 norm is r, and every refreshed probability error is at most epsilon, then before additional reduction error:

`sum(actual_p^2) >= max(0,m-K*epsilon)^2/K`, and `sum(actual_p^2) <= (r+sqrt(K)*epsilon)^2`.

Subtract/add separately measured reduction error for an actual domain guarantee. These bounds do not assume each refreshed probability remains positive, and broad domain membership does not imply acceptable logit error. At K128, reciprocal sensitivity near1/128 and correlation between the retained square numerator and denominator matter. The isolated130-rule tracked reciprocal proof at N65536 is evidence for that component only; it does not certify joined N131072, refreshed inputs, repeated rounds or attention error. All decoded comparisons must happen after server completion against independent private polynomial and native references. No clipping, decoded branching, native intermediate substitution or gate weakening is proposed.

The v2 attention LayerNorm domain is[.2669251572966357,1.4255030943618103], polynomial SHA256 `8a5d76da10bcf0b005c7529a2cffec56d717d3c4f03b01658d28fb767f18ad46`. The successful historical p60 row-normalization component used different coefficients/domain and cannot establish this one. Complete attention error has no new native block gate invented here; preserve the original P2/operator/full-model gates and report polynomial-versus-native and HE-versus-polynomial differences separately.
