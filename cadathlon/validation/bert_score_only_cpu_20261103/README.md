# Score-only BERT attention: CPU planning evidence

The isolated plaintext candidate passed seven pinned full-width BERT layer-zero cases in **8.86 seconds**, with six measured source hashes unchanged and a reaped exit-zero process. Maximum absolute error was **2.50e-10** for probabilities, **5.26e-10** for attention context, and **2.50e-10** after the remaining exact layer-zero operators. Cases include independent query rows, padded queries, head padding, boundary key masks, a single final key, and a partial 17-token tile.

This is **not an encrypted or practical full-model design**. Only softmax uses the proposed arithmetic. Public dense projections and the remaining GELU/LayerNorm block are plaintext oracles. There is no MRPC evaluation, checkpoint generation claim, or CKKS rounding/refresh evidence.

The [fixed manifest](manifest.json) declares centered scores in `[-16,16]`, degree-eight exponential approximation on `[-0.5,0.5]`, five normalized squarings, and fixed Newton reciprocal iterations: six initially and thirteen per square. The thirteen-round choice follows an analytic residual bound for up to 128 public valid keys, not output/label fitting. The candidate uses no exact exponential, private reciprocal, clipping, or private stopping rule. Those functions appear only in separate oracle/analytic-grid checks. The declared domains had zero failures on these cases; the historical `[-9,12]` interval still has **22 failing tile records**. Neither interval is certified for unseen inputs.

Each score tile packs 16 queries × 128 keys × 16 padded heads into 32768 slots, repeated twice. [Exact layout checks](layout.json) cover all 128 compaction/scatter maps; selected boundary maps also execute literal rotation/mask sums. [Composed-rotation checks](rotation_plan.json) establish exact NumPy parity and verify the displacement decomposition for all 65536 rotations. The required 31 signed power-of-two keys already occur in the planned 190-key full graph, so thousands of extra stored keys are unnecessary.

**The execution cost remains prohibitive:** the best tested public BSGS split requires **1,017,160 composed rotations per 128-token example for compaction/scatter alone**. This excludes attention, dense layers, softmax reductions and refresh. The default split requires 1,596,840. Every extra real key switch adds error and runtime that this plaintext proof does not measure. The chosen abstract softmax schedule adds 226 levels and 148 ciphertext-like products per score tile before layout/attention costs. Period 32768 has only two aliases and is not covered by the earlier period 128 refresh proof. Reciprocal intermediates can reach 128 for uniform probabilities; the declared reciprocal interval permits values up to 256. Thus final probabilities bounded by one do not justify the validated bound-16 refresh path inside the 226-level circuit. Separate intermediate range, scale and accumulated refresh-error proofs are required. No further optimization or feasible execution claim follows from this result.
