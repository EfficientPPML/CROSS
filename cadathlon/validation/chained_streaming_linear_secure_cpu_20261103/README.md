# Secure CPU chained linear component

The three independent pinned BERT layer-0 linear maps passed the fixed absolute error gate of 1e-6 over every one of 8,192 physical slots. Query, intermediate and output errors were 3.44930e-11, 3.64730e-11 and 3.41429e-11. Inputs included two distinct rows, a partial tile with hostile unused rows, and a signed public source mask. All maps consumed exactly one level (1→0), retained canonical scale and NSD1, and left their input payloads/metadata unchanged.

The actual 128-bit classical secure profile was N16384, Q4/P3, dnum2, p56, layout128×128, log2(QP)=206.9965209855. Only four public rotation keys were supplied: {1,64,4416,6720}. Actual nonzero rotation counts were 86/122/122, with 24/60/60 weighted sums and 1535/3839/3839 plaintext products. Internal wall time including cleanup was 332.97245 seconds; peak RSS was 697,840 KiB. These timings are not a controlled comparison against the direct strategy.

Fresh client keys and a separate keyless server object were used in one dedicated CPU process, not an OS sandbox. Both key-generation import aliases were guarded before server initialization. Seven class codec APIs remained disabled through all three outputs; client decryption occurred only afterward. The exported public weights were byte-verified against their pinned original checkpoint offsets. Synthetic input rows are not native BERT hidden states.
