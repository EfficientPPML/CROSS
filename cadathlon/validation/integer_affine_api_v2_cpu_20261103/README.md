# Isolated integer-affine API hardening v2

This **unpromoted** candidate passed55 source-bound CPU contract tests and a separate genuine secure two-update regression. It does not replace or retroactively change the [original thirteen-update measurement](../integer_newton_thirteen_cpu_20261103/README.md).

The helper now rejects Boolean, complex and object estimates before float64 coercion, including mixed Boolean/real lists. It rejects underflowed initial coefficients, nonfinite alignment scales, nonzero public coefficients below the encoding-resolution guard and a nonzero public coefficient array that actually encodes to the zero plaintext. That last check inspects only the encoded **public plaintext** buffer; it never inspects ciphertext slots. It can add synchronization/transfer cost, which is not benchmarked here.

The fixed Newton generator requires a CD2/explicit-NSD1 leveled context and enough levels for the entire schedule. It forbids a refresher, computes the public binary64 scale recurrence before arithmetic, and checks the actual level/scale/NSD after every primitive and at every yielded checkpoint. Changing the context/cache, source modulus prefix, denominator metadata, yielded metadata or refresh setting while the generator is suspended fails closed. Metadata is checked, never relabeled. These guards do not establish encrypted-domain membership, convergence or an all-input noise bound; arbitrary concurrent mutation of runtime internals remains outside the dedicated-process contract.
