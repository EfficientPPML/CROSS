# Qwen causal PV and attended rows

This isolated successor adds actual ciphertext-operation loops for causal P@V to the unchanged, source-bound 72-test Qwen D128/Q16/K8 head-routing owner. `QwenAttentionRouting.attend(probabilities, expanded_value_tiles, query_tile=...)` borrows the same initialized keyless context. The caller supplies ciphertext probabilities and the ordered expanded V tiles. This module does not implement or substitute RMSNorm, softmax, refresh, codecs or full-model inference.

For each key, the owner extracts only public causal probability lanes from feature32h+k, moves them to head128 anchors and broadcasts over128 features. It separately broadcasts the appropriate expanded V row, multiplies the two ciphertexts, and accumulates keys. A final real weighted mask clears inactive rows/features in the ideal circuit. The critical depth is at most three levels below the minimum input, with two further levels reserved. Every weighted/product/add output is checked against the actual binary64 scale recurrence and exact layout metadata; no scale is relabeled. Inherited construction, key inventory and callback guards also cover the retained probability broadcast and accumulated output.

The 88-test combined suite runs the actual predecessor and PV loops with NumPy payload/primitive doubles. S1/8/16/19/32 cases cover distinct rows and heads, shifted original positions, partial final tiles, hostile future lanes and padding, and all65536 physical output slots against an independent dense P@V oracle at5e-14. The test explicitly creates **public probability stand-ins** from the preceding actual score-loop output. Its clear exponential/normalization is fixture preparation, not a frozen encrypted softmax implementation. V padding is deliberately hostile. Exact primitive counts, source immutability, retained callback guards and public key inventory checks are asserted.

`plan_public.py` independently authenticates the predecessor report/archive/runtime/test bytes, and records the combined component key inventory, primitive counts and actual ordered-prime scale recurrence. Raw key bytes are not a peak memory claim or the complete Qwen key union. `collect_public.py` binds exact before/archive/after source bytes, reaps test children and preserves terminal failures. `verify.py` reproduces the public plan and archive checks offline.

Development-v1 passed88 checks before the final source-bound collector was added. No development failure occurred in this successor. The predecessor's earlier oracle and metadata failures remain in its separate immutable archive. These are ideal/public component checks: the crypto type/security seam is replaced by test doubles, so no actual security, key generation, HE accuracy, performance, memory or model-readiness claim follows. No model tensors, tokens, native outcomes or payload arrays are archived. No runtime promotion or encrypted launch is performed.
