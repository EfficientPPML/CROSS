# Isolated layer-indexed BERT attention

This owner preserves the pinned twelve-layer BERT-v2 arithmetic contracts and public model tensors. It is a component implementation and ideal graph test, not an encrypted result or a file-stage backend.

Layer0 retains the existing eight fresh canonical L49 inputs. For later layers, exactlyT compact valid prior outputs enter at their actual low levels and scales. Each input receives an explicit B128 full-slot refresh to L25. The remaining padded frame tiles are real same-level ciphertext subtractions x−x; all eight key/value projections still run. Q/K projections reach L24 and all-key scores L21. The selected complete softmax preserves the per-layer centered-score domains and5/6/7 squaring rounds, ending with B2 refresh and a mandatory real mask at L24. PV reaches L21, output dense and residual L20, then the selected attention normalization reaches L9 or L8.

All input, retained-frame, key/value and returned-output objects are guarded across callbacks. The owner never closes borrowed arithmetic or refresh services, infers a private range, invokes a codec, or replaces a model intermediate with a native value. The public contract binds each layer's exact projection weights, context profile, ordered original positions and actual ciphertext descriptor levels/scales. It supplies metadata validation, not a serializer.

Independent native fixtures cover the same two fixed public pairs, K15 and K128. They are prepared separately by a pinned native model and stay outside repository archives. For each layer, the ideal test consumes that layer's native input and compares the actual helper loops against a separate dense polynomial reference, with propagated-domain checks and all physical output slots. These per-layer tests do not prove twelve-layer composition. A future joined graph must feed each actual prior output directly, then establish CKKS, repeated-refresh and final numerical gates.
