Isolated public-mask guard candidate. No running owner/common source was changed.

Current layouts merely disable ndarray writeability, which can be reversed through the owning array or its mutable base. The candidate constructs identical standard ndarray masks backed directly by immutable Python bytes. Each ScoreReduction binds every ndarray/backing-chain identity, dtype, shape, strides, data pointer and writeability, and typed valid_rows. Its existing full byte digest is computed once only when all six arrays meet that immutable-storage contract. Any legacy/custom mutable-backed layout retains the complete hash on every guard. Equal-byte replacement arrays fail closed in the immutable path.

This changes public storage and mutation checking only, not masks, primitive order, levels, scales, or arithmetic. It does not defend against ctypes/native code writing arbitrary process memory, nor callers rewriting the guard's private implementation. The measured tests inspect NumPy contracts and exact mask bytes only; guard timing excludes construction and model/HE execution. Whole-model parity, existing broader guard regressions and a separately measured end-to-end effect are still required before integration.
