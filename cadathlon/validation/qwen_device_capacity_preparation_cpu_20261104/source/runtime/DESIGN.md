# Pure full28 scientific prerequisite admission

This source draft authenticates public scientific evidence for the fixed expanded candidate1 and fixed checkpoint token0/original-position0 input. It performs no file or body access, numerical recomputation, model execution, key/context operation, process launch, or grant issuance. No actual proof bundle or successful admission instance is included. All added code is source-only and untested.

The caller supplies independently admitted expected pins. A report's own hashes, or an arbitrary caller-created ExpectedScientificPins object, do not establish authority. The eventual entry must select this exact code and all prerequisites, authenticate the externally pinned packet and source/archive closure, and separately enforce its phase grant, current stores, backend, resources, and process ownership.

## Interface and encoding

`authenticate_scientific(public, model, readiness, request_bytes, request_manifest_bytes, statement_bytes, *, proofs, expected_pins)` returns exact frozen `ScientificAdmission`. Its `check()` reauthenticates retained immutable proof bytes and dependencies; `statement_bytes` is immutable bytes; `bindings()` returns the closed binding dictionary. `execution_authorized` is always false. `create_actual_scientific_authorization` immediately denies.

`ExpectedScientificPins(raw)` requires canonical compact JSON plus one newline, the existing Qwen public encoding. It binds the exact statement digest, closed bindings/evidence, and actual server's complete source map. Its map digest is SHA256 of that same canonical encoding. This is distinct from the historical freeze encoding (compact JSON without newline), the exact historical pretty source manifests, and exact producer report bytes. Those historical bytes are hashed without rewriting. The supplied model proof must be admitted for this exact server source-map digest. Its four actual body-validation evidence hashes (manifest, report, outer, root review) must equal GeneratedKeyReadiness's generation model evidence; the consumer-specific ExpectedModelPins bytes may differ.

`proofs` is an exact dictionary of 25 names to original UTF-8 JSON bytes. An enclosing packet may transport strings and UTF-8 encode each string without parsing/reformatting it first. `PROOF_LINKS` and `PROOF_LIMITS` are normative. Six parent/worker reports retain the existing 32MiB per-report bound; seven historical source/receipt/review objects are at most 1MiB each; twelve new or small root/outer objects are at most 64KiB each. Their maximum raw-byte total is 209453056 bytes. This parser ceiling is not a memory/headroom grant: the future enclosing packet must separately bound its encoded size and admit actual parsing/retention resources. Statement is at most 64KiB, ExpectedScientificPins at most 2MiB, request and upload manifests at most 1MiB each.

The selected pure local imports are listed in `import_closure.json`; historical runtime modules are neither copied nor imported. Exact copies of freeze_issuer and freeze_admission retain their original names and bytes. The future server entry must allowlist these names explicitly and use this module name, `qwen_scientific_admission`.

Exact source/archive membership and externally observed normal-return, exit/reap/group absence remain the independent root verifier's responsibility. The embedding provenance producer/root implementation and actual receipts remain missing.

The statement sets scientific prerequisites satisfied only under all these verified public bindings, while explicitly keeping actual execution, HE precision, client-result acceptance, candidate selection/revision and heldout retry unauthorized.
