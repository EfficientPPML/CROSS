# Qwen native/exact calibration trajectories

The frozen synthetic calibration corpus completed 416 CPU contexts: 288 prefills (96 distinct token sequences each at S=8,16,32), 64 teacher-forced decisions and 64 free-running decisions from 16 seeds. Each context compares all151936 final logits from the pinned native float32 model with the independent float64 exact oracle. All fixed semantic gates passed: maximum absolute error7.7498013e-5 (gate1e-3), maximum nRMSE2.9042685e-6 (gate1e-5), exact argmax on every context, 64/64 teacher decisions and16/16 complete greedy sequences.

This is calibration/reference evidence. No polynomial coefficients were selected, no approximate forward or HE operation was evaluated, and no held-out validation extrema, logits or generated outputs were read. The corpus, token prefixes, slack rules, analytic targets, balanced-Chebyshev option and original numerical gates were frozen in `qwen_calibration_protocol_20261103` before model evaluation. Calibration decode seeds overlap calibration prefills intentionally. These observations do not establish unseen-input bounds, language-task accuracy, hidden-suite calibration, or encrypted performance.

Both native and exact trajectories cover169 required nonlinear input sites: four RMS variances per layer, SiLU inputs and mean-centered causal scores in all28 layers, plus the final RMS variance at the required last position. Exact count verification covers every needed token/head/key. Normalization-output and RoPE ranges are also recorded separately for planning. Final native/exact union ranges, grouped and aggregate, are in `native-exact-v1/report.json`; no hidden activation arrays are stored. The shared labels permit a subsequent candidate to use calibration-only input ranges under the already frozen protocol. All seven pinned checkpoint/tokenizer asset hashes match before/after.

Four contexts independently compare instrumented against uninstrumented native logits and instrumented against the untouched exact oracle, bitwise across all output logits. Six prelaunch focused tests cover tiny bitwise semantics, counts, causal prefixes, hook restoration, decode histories and fixed gates. The smoke run covers11 contexts; the full run uses identical22 selected source files. Each run archives those bytes before evaluation and checks them afterward. Selected Transformers Python modules and installed package versions are included; this is not an entire OS/binary reproducibility image.
