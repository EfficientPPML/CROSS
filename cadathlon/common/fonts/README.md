# Embedded tutorial typography

The handouts use the same Inter body font and Outfit heading font as
`CROSS_Tutorial/index.html`. Both are bundled and embedded in the HTML and PDF
so rendering does not require Google Fonts or another network connection.

Original variable fonts from the Google Fonts repository, retrieved 2026-09-20:

- [Inter](https://github.com/google/fonts/tree/main/ofl/inter): `Inter.ttf`, with `Inter-OFL.txt`.
- [Outfit](https://github.com/google/fonts/tree/main/ofl/outfit): `Outfit.ttf`, with `Outfit-OFL.txt`.

The fonts are distributed under the SIL Open Font License 1.1. The HTML files
also carry the font license notices because they embed copies of these fonts.
